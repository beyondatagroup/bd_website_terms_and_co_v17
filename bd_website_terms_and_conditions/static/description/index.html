Configuration

Install the Custom Captcha module

Once you install this module, navigate to General Settings, where you will find the Captcha option. Enable it to activate the functionality.

Now, whenever a user logs in or signs up, a Captcha will be displayed to ensure human access and enhance security.

The user will find a Refresh button that allows them to generate a new Captcha code upon clicking. This functionality is also available during the sign-in process.
